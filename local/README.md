# Отметка — журнал посещений

Распакуйте архив в отдельную папку. Для запуска нужен Node.js 22.13 или новее. Дополнительные пакеты устанавливать не требуется.

## Запуск сайта

Откройте терминал в распакованной папке и выполните:

    node local/server.mjs

Откройте http://127.0.0.1:8000 в браузере. Оставьте терминал с сервером открытым. Для остановки нажмите Ctrl+C.

## Проверка работы

1. Выберите «Регистрация». Укажите имя, уникальный логин и пароль длиной от 8 символов. Первый зарегистрированный аккаунт получает роль администратора.
2. Войдите в этот аккаунт. Выберите даты и нажмите «Показать». Ваш первый вход появится в таблице. Обновите страницу — число входов останется прежним.
3. Выйдите и зарегистрируйте второй аккаунт. Вернитесь в аккаунт администратора. В сводке у второго пользователя будет ноль, пока он не войдёт.
4. Войдите во второй аккаунт. В его кабинете доступна личная история. Под администратором можно открыть историю любого пользователя за выбранный период.

## Консольный просмотр

В отдельном терминале из той же папки выполните:

    node local/console.mjs

Введите логин и пароль, начальную и конечную даты в формате ДД.ММ.ГГГГ. Вы получите таблицу. Введите ID для истории пользователя, Enter для нового периода или 0 для выхода. Логин через консоль тоже считается входом.

В браузере кнопка «Консоль» открывает текстовый просмотр уже начатой сессии. Доступны команды «помощь», «сводка», «период ГГГГ-ММ-ДД ГГГГ-ММ-ДД», «история ID» и «выход».

## Данные и время

Успешный вход создаёт одну запись. Регистрация, неудачная попытка входа и обновление страницы её не создают. Входы хранятся с абсолютной отметкой времени. Программа отображает их в часовом поясе устройства и включает в отчёт обе выбранные даты полностью.

Локальная база SQLite создаётся при первом запуске в файле otmetka.sqlite в папке проекта. Аккаунты и журнал сохраняются после перезапуска. Права администратора и проверка доступа применяются на сервере. Пароли хранятся в виде хешей с индивидуальной солью. Локальный сервер принимает подключения с этого компьютера. Локальная и размещённая версии используют отдельные базы данных.

## Состав проекта

- public — интерфейс сайта
- core — регистрация, авторизация, отчёты и проверка прав
- migrations — схема базы данных
- local/server.mjs — локальный HTTP-сервер
- local/console.mjs — консольный клиент
- local/database.mjs — подключение SQLite
